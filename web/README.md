# crochet-sim web

The viewer for [crochet-sim](../README.md) — currently a **minimal
viewer** (M4), not yet a scheme editor (that's M5). See
[`../HANDOVER.md`](../HANDOVER.md) for the full picture and
[`AGENTS.md`](./AGENTS.md) for this directory's specific conventions and
gotchas (WASM asset resolution, `allowedDevOrigins`,
`preserveDrawingBuffer` — each cost real debugging time once; don't
rediscover them).

## Run locally

```bash
npm install
npm run dev          # http://localhost:3000
npm run lint
npm run build
npm run test:e2e      # Playwright — starts its own dev server on :3100
```

`lib/wasm/` holds the compiled simulation engine (generated by
`wasm-bindgen` from `../wasm/`) — see the root README for the rebuild
command after changing `../core/` or `../wasm/`.
